# ما بنيناه — وصول (WUSOOL)

**بجملة واحدة:** نظام بحوّل العناوين الفلسطينية العامية لإحداثيات GPS، بتعلّم من كل توصيلة، بوجّه السواقين بعيد عن الحواجز، وبربط العنوان العامي بالسجل الرسمي للبلدية.

---

## المشكلة اللي بنحلها

فلسطين ما فيها نظام عنونة موحّد. الناس بتقول "قرب المسجد، خلف الصيدلية، بعد الدوار الثاني" — جوجل ما بيلاقي هالعنوان. السائق بتصل 3-5 مكالمات كل توصيلة. الطلبات اللي بترجع بالدفع عند الاستلام بتكلّف التاجر 15-30 شيكل للطلب الواحد.

---

## شو النظام بيعمل بالزبط

### 1. بيفهم العامية الفلسطينية

الذكاء الاصطناعي (Gemini) أو محرّك القواعد المحلي بيستخرج من النص: المدينة، المبنى، المعالم، الطابق، العلاقات المكانية (قرب، خلف، فوق، مقابل).

مثال:
```
الإدخال: "رام الله، التحتا، قرب عمارة النتشة، فوق سوبرماركت الأمل، طابق ٣"
النتيجة: مدينة=رام الله، حي=التحتا، مبنى=عمارة النتشة، معلم=سوبرماركت الأمل، طابق=3
```

### 2. بيحدد الموقع على الخريطة — 4 مستويات

| المستوى | السؤال | الدقة |
|---|---|---|
| 1 | هل هالشخص أرسل هالعنوان قبل؟ | 0.98 — فوري |
| 2 | **هل حدا بنفس العمارة ثبّت موقعه قبل؟** (تأثير الجار) | 0.80 — فوري |
| 3 | فيني أحدد الموقع من المعالم المذكورة؟ | 0.55-0.80 |
| 4 | عنوان جديد كلياً — بطلب تثبيت مرة واحدة | 0.20 |

**المستوى 2 هو قلب النظام:** زبون واحد بثبّت عمارة زيدان — كل ساكن بنفس العمارة بعدها بنحل فوري. هاد هو الـ flywheel.

### 3. بيربط بالعنوان الرسمي — بلدية رام الله

بعد ما نحدد الإحداثيات، بنستعلم من نظام GIS لبلدية رام الله ونجيب:
- اسم الحي الرسمي (مثلاً: حي قدورة)
- رقم الحوض (مثلاً: 19-المدينة)
- العنوان الشارعي (مثلاً: 16 شارع خليل صلاح)
- الرمز البريدي (مثلاً: 6008960)

**هاد الجسر اللي ما حدا بناه قبل:**
```
"عمارة زيدان قرب المسجد"     ← كيف الناس بتحكي
        ↕
  31.9033, 35.2058            ← GPS (كيف تلفون السائق بيفهم)
        ↕
  حي قدورة، 16 شارع خليل صلاح  ← كيف البلدية بتحكي
```

### 4. بيوجّه السواقين بعيد عن الإغلاقات

- بلاغات من تلغرام وواتساب بتغذّي حالة الحواجز
- محرّك القواعد بيفهم العامية: "مسكر" = مغلق، "سالك" = مفتوح، "عجقة" = ازدحام
- وكمان بيفهم النفي: "مافي زحمة" = الطريق فاضي (مش ازدحام!)
- OSRM بيحسب أسرع طريق بيتجنب الحواجز المغلقة
- السائق بيشوف ليش تغيّر المسار: "حاجز الكونتينر مغلق — تم التحويل تلقائياً"

### 5. بيتعلّم من كل توصيلة

```
يوم 1: زبون أ بثبّت عمارة زيدان ← المبنى بتسجّل إحداثياته
يوم 2: زبون ب بكتب "بناية زيدان" ← تحديد فوري، بدون تثبيت
يوم 30: كل سكان العمارة ← صفر مكالمات، صفر تثبيت
```

### 6. نظام النقاط

- تثبيت موقع المبنى = +10 نقاط
- منطقة جديدة (مكافأة استكشاف) = +10 نقاط
- كل 50 نقطة = خصم 5 شيكل على الطلب القادم
- جيرانك بنفس العمارة كمان بيكسبوا نقاط

## المنتج — 3 شاشات موبايل

**شاشة الزبون** — اكتب العنوان ← شوف التحليل ← أكّد على خريطة القمر الصناعي ← اكسب نقاط

**شاشة السائق** — خريطة حقيقية + مسار OSRM + تنبيهات الحواجز + إتمام التوصيل

**لوحة التحكم** — مؤشرات الأداء، المعالم المتعلّمة، أحداث الطرق، قياس الدقة

## التقنيات

Node.js، TypeScript، SQLite (مدمج)، Express، Leaflet. بدون خطوة بناء، بدون تحميلات إضافية، بيشتغل بدون إنترنت.

```bash
npm install && npm run seed && npm run dev
# افتح http://localhost:4000
```

## ليش إحنا مختلفين

ما حدا ثاني بيربط هالثلاث عوالم:
- **العامية** — كيف الفلسطيني بيوصف عنوانه
- **GPS** — كيف تلفون السائق بيفهم
- **السجل الرسمي** — كيف البلدية بتحكي

جوجل عندها GPS بس ما بتفهم العامية. البلدية عندها الأحواض بس ما عندها العناوين الوصفية. وصول هو الجسر — وكل توصيلة بتخليه أقوى.

**عنوانك واصل.**
